## 📖 Question Format

Every question follows a consistent structure:

- **QUESTION** — Problem statement with example
- **THOUGHT PROCESS** — Step-by-step reasoning from brute force to optimal
- **COMPLEXITY** — Time and space analysis
- **EDGE CASES** — Empty input, single element, duplicates, negatives
- **IMPLEMENTATION** — Clean Python code with optimal approach

---

## 🧠 Core DSA Problem-Solving Framework

1. **Understand** — Input/output types, constraints, brute force first
2. **Identify Pattern** — Two pointers, sliding window, BFS/DFS, DP, etc.
3. **Analyze Complexity** — Time vs space trade-offs
4. **Test Edge Cases** — Empty, single, duplicates, negatives

---

## ⚡ Key DSA Patterns Cheatsheet

| Pattern | When to Use |
|---------|-------------|
| **Two Pointers** | Sorted array, palindrome, in-place |
| **Sliding Window** | Contiguous subarray/substring |
| **Monotonic Stack** | Next greater/smaller element |
| **Slow/Fast Pointers** | Cycle detection, middle of list |
| **BFS** | Shortest path, level order |
| **DFS** | Exhaustive search, path finding |
| **Binary Search** | Sorted data, boundary finding |
| **Topological Sort** | Dependency ordering |
| **Union Find** | Connected components |
| **DP: Memoization** | Overlapping subproblems |
| **DP: Tabulation** | Bottom-up optimization |
| **Backtracking** | All permutations/combinations |
